Checked 13 October 2026. One-page generic product introduction, without competitor comparison. Four supplied PDFs were read directly and their product images extracted. Benefits describe supported workflows, not measured customer savings.

[1] Four format options

The supplied 1.6-inch PDF identifies model T1.6 and a 1.54-inch, 200 × 200 active display. The 2.1-inch PDF gives a 2.13-inch, 250 × 122 display. The supplied T2664 PDF calls its display 2.6 inches and 184 × 360 pixels, while the local Chinese original and overview use 2.66 inches. The 4.2-inch PDF states 400 × 300. The four figures on the slide are nominal size options, not measurements of the label shown in the user-supplied concept image. The brief use cases describe typical layout fit as available display space increases; they are not exclusive assignments or a promise that every template fits every variant. The local Hub previously lacked a valid 1.6-inch spec; the newly supplied valid PDF supports this presentation but does not constitute a knowledge-base synchronization.

[2] Four-color e-paper display

All four supplied specifications support four-color content. The 1.6/2.1/4.2 detailed display tables and the product memory identify black, white, red and yellow. Alternative two/three-color configurations vary by line. Four colors do not mean full RGB color or video. The 1.6/2.1/4.2 specifications state viewing angles greater than 170 degrees; no viewing-angle value is inherited by T2664. Promotion highlighting is a template-design benefit rather than a quantified sales-uplift claim.

[3] Central wireless price management

The overview slides 16 and 18 describe product/template/tag binding, push updates, flash tasks and execution feedback through the matching base station. The memory explains proprietary 2.4 GHz tag communications, so standard Wi-Fi access points do not replace the ESL base station. Integrating the approved pricing source with the platform can reduce manual replacement and help maintain consistency; it cannot guarantee that every price and checkout record always match. Binding, correct source data and update verification still matter. RF coverage needs a site assessment. Conflicting 30/50/100 m, refresh-throughput and batch-time figures are omitted from this generic introduction.

[4] Low power and maintenance planning

The 1.6-inch specification lists one CR2450 and minimum five years. The 2.1-inch specification lists two CR2450 cells and minimum seven years; the 4.2-inch specification lists three CR2450 cells and not less than seven years. No common test profile is stated. T2664 lists two built-in batteries and 3 µA sleep current but no lifetime in years. The older overview claims 15 years under a twice-daily refresh condition; the September memory says at least five years with daily refreshes. These figures cannot be merged into a family-wide guarantee. The main slide therefore emphasizes low power and maintenance planning, not a guaranteed year count. Battery/power sampling is explicit in the 1.6/2.1/4.2 PDFs and the platform overview supports low-battery monitoring.

[5] Templates, languages and codes

The 1.6/2.1/4.2 specifications describe text, promotional information, QR codes, barcodes and transmission of language characters/images. T2664 supports custom four-color images addressed to its unique ID. The overview lists customizable templates; memory explains server-side font rendering, sending a rendered image to the tag. Actual font availability, script shaping, reading direction, resolution and code readability need validation with the customer layout. “Any language” is not a promise that every font comes preinstalled.

[6] Configurable LED for finding an item

The 1.6/2.1/4.2 specifications list RGB LEDs with configurable flashing. The overview describes visual picking tasks, while memory positions this as occasional product locating rather than a dedicated continuous beacon. LED colors are separate from the four e-paper display colors. The specification says seven combined LED colors; memory describes six, so no exact color count is presented on the slide. T2664 has no explicit LED-function row in the supplied specification. Picking and replenishment guidance require supported hardware, item bindings and an application workflow.

[7] Protection is specific to the quoted size and option

The supplied 1.6/2.1/4.2 PDFs list IP65 default and IP68 optional. T2664 has no explicit IP rating in its supplied PDF, so IP65/IP68 are not represented as universal across all four images. The older presentation uses broader IP68 language, which does not override the size-specific tables. IP68 does not by itself establish suitability for pressure washing, detergent exposure or arbitrary immersion. Default four-color 1.6/2.1/4.2 variants generally specify 0–40 °C; T2664 specifies −20–60 °C. Confirm temperature, humidity, refresh behavior and any cold-storage option for the exact model.

[8] One ecosystem with deployment options

The overview describes UROVO labels, matching base stations and management platform. Supplied 1.6/2.1/4.2 PDFs support cloud or local deployment, with optional serverless management in a base station. Memory describes integration through RESTful APIs or a separately developed database-polling middleware. API support does not mean zero implementation work or automatic compatibility with every ERP. Phone-only NFC/Bluetooth workflows differ by model and conflict with the memory’s practical emphasis on base-station updates, so they are not advertised as the generic deployment path. NFC is optional in the detailed size tables.
